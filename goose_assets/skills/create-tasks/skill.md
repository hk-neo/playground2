구현 태스크들을 생성합니다. Bottom-Up 순서: 부품부터 조립까지.

## 사용 위치

- SDS (Detailed Design) Document에서만 사용

## 생성 방식

1. **Bottom-Up 분석**
   - 가장 하위 컴포넌트(단일 함수/클래스)부터 시작
   - 의존성 그래프 생성

2. **의존성 기반 순서**
   - 선행 태스크가 없는 것부터 생성
   - 각 태스크에 blocks 링크로 의존성 설정

3. **태스크 크기 조정**
   - 너무 큰 태스크는 분할
   - 너무 작은 태스크는 병합

## 수행 단계

1. **SDS 문서 분석**
   - 컴포넌트 목록 추출
   - 인터페이스 정의 확인
   - 의존성 관계 파악

2. **태스크 목록 작성**
   - Bottom-Up 순서로 정렬
   - 각 태스크에 제목, 설명, 예상 시간 할당

3. **태스크 생성**
   - Jira API로 일괄 생성
   - 각 태스크에 blocks 링크 (의존성)
   - 상위 SDS 티켓과 parent 링크

4. **결과 보고**
   - 생성된 태스크 목록
   - 의존성 시각화
   - 총 예상 시간

## 태스크 분류 예시

```
TASK-01: 데이터 모델 정의 (선행 없음)
TASK-02: API 인터페이스 정의 (blocks TASK-01)
TASK-03: 비즈니스 로직 구현 (blocks TASK-02)
TASK-04: UI 컴포넌트 구현 (blocks TASK-02)
TASK-05: 통합 테스트 (blocks TASK-03, TASK-04)
```

## 주의사항

- 이미 존재하는 태스크는 중복 생성하지 않음
- 순환 의존성 감지 시 경고
