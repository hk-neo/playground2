티켓 내용을 수정합니다.

## 옵션

| 옵션 | 설명 |
|------|------|
| 없음 | 현재 티켓 내용만 수정 |
| --preview | 미리보기만 (실제 수정 안 함) |
| --cascade | 연쇄 수정 활성화 |
| --direction={up,down,both} | 전파 방향 (기본: both) |
| --depth={N} | 전파 깊이 (기본: 1) |

## 수행 단계 (기본)

1. **수정 내용 분석**
   - command_args로 전달된 수정 내용 파싱

2. **미리보기 확인** (--preview인 경우)
   - 변경될 내용 표시
   - 실제 수정하지 않음

3. **티켓 내용 업데이트**
   - Jira 필드 업데이트
   - 코멘트로 수정 완료 통보

## 첨부파일 처리 (plan.md)

1. **기존 첨부 확인**
   - plan.md 첨부파일이 있는지 확인

2. **새 파일 생성**
   - command_args에 따라 새 plan.md 생성
   - 또는 제공된 파일 사용

3. **첨부 교체**
   - 기존 plan.md 삭제
   - 새 plan.md 첨부

## 연쇄 수정 (--cascade)

1. **영향 분석**
   - 현재 티켓의 상위/하위 연결 확인
   - 지정된 깊이(depth)만큼 추적

2. **대상 목록 작성**
   - 영향받을 티켓 목록 표시
   --preview 시 여기서 멈춤

3. **일괄 수정**
   - 각 대상 티켓에 맞게 내용 수정
   - 코멘트로 연쇄 수정 통보

## 예시

```
!update "기능 추가"
!update --preview
!update --cascade both 2 "요구사항 변경"
```
