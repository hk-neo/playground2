plan.md에 정의된 계획대로 구현을 수행합니다.

## 수행 단계

1. **plan.md 확인**
   - 첨부된 plan.md가 있는지 확인
   - 없으면 에러 반환 ("!plan을 먼저 실행하세요")

2. **계획 읽기 및 분석**
   - plan.md 내용 파싱
   - 구현 순서, 범위 확인

3. **구현 수행**
   - 정의된 순서대로 구현
   - 각 단계 완료 시 진행상황 코멘트

4. **테스트 수행**
   - plan.md에 정의된 테스트 전략에 따라 테스트
   - 실패 시 수정 후 재시도

5. **코드 커밋**
   - 구현 내용을 Git 커밋
   - 커밋 메시지: `[{TICKET_KEY}] Implement: {요약}`

6. **완료 통보**
   - Jira 상태 업데이트
   - 코멘트로 완료 보고
   - plan.md를 완료 버전으로 교체 (선택)

## 주의사항

- plan.md가 없으면 에러 반환
- 예상 범위를 벗어난 작업은 하지 않음
- 테스트 통과 후에만 완료로 간주
