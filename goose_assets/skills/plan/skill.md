Task 티켓에 대한 구현 계획을 생성합니다.

## 수행 단계

1. **티켓 컨텍스트 수집**
   - 현재 티켓 정보 읽기
   - 상위 티켓(SDS)에서 관련 요구사항 확인
   - 연결된 티켓들(의존성) 확인

2. **계획 작성**
   - 구현 범위 정의
   - 필요한 파일/컴포넌트 목록
   - 구현 순서 (의존성 고려)
   - 테스트 전략
   - 예상 작업 시간

3. **plan.md 생성**
   - 마크다운 형식으로 계획 작성
   - 한국어로 작성

4. **Jira 첨부**
   - 기존 plan.md 첨부파일이 있으면 삭제
   - 새로운 plan.md를 첨부
   - 코멘트로 완료 통보

## plan.md 템플릿

```markdown
# 구현 계획: {티켓 제목}

## 1. 개요
- 티켓: {TICKET_KEY}
- 작성일: {날짜}

## 2. 구현 범위
- 구현할 기능/요구사항
- 포함하지 않을 내용

## 3. 의존성
- 상위 요구사항: {목록}
- 선행 태스크: {목록}

## 4. 구현 순서
1. ...
2. ...
3. ...

## 5. 필요한 파일/컴포넌트
- ...
- ...

## 6. 테스트 전략
- 단위 테스트
- 통합 테스트
- ...

## 7. 예상 작업 시간
- 총: {시간}
```
