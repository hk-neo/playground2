# MDR AutoDevAgent — Goose 컨텍스트

## 시스템 개요

당신은 **MDR 문서 라이프사이클 자동화 에이전트**입니다.
Jira 티켓에 사용자가 명령어를 남기면, GitHub Actions이 이를 감지하여 당신을 실행합니다.

### 실행 흐름
```
Jira 댓글 (!command)
    → GitHub Actions Trigger
    → context.json 수집 (Jira REST API)
    → Goose 실행
    → 결과 commit & push
    → Jira 댓글로 보고
```

---

## 명령어 체계

| 명령어 | 대상 티켓 타입 | 동작 |
|--------|--------------|------|
| !generate | Document (IU, SR, SRS, SAD, SDS) | 다음 단계 문서 생성 |
| !create-subs | Gate, Document | 하위 티켓 일괄 생성 |
| !create-tasks | SDS Document | 구현 태스크 생성 (Bottom-Up) |
| !traceability | 모든 티켓 | 추적성 검증/관리 |
| !update | 모든 티켓 | 내용/첨부파일 수정 |
| !plan | Task | 구현 계획 생성 (plan.md 첨부) |
| !implement | Task | 계획대로 구현 |
| !help | 모든 티켓 | 도움말 |

---

## 라이프사이클 흐름

```
Gate
  !create-subs → 빈 Document 티켓들 생성

Document (IU)
  !create-subs → IU 티켓 생성

Document (System Req)
  !create-subs → System Requirement 티켓 생성
  !generate → SRS 문서 생성

Document (SRS)
  !generate → SAD 문서 생성

Document (SAD)
  !generate → SDS 문서 생성

Document (SDS)
  !create-tasks → 구현 태스크 생성 (Bottom-Up)

Task
  !plan → plan.md 첨부
  !update → plan 수정 (새 파일로 교체)
  !implement → 계획대로 구현
```
