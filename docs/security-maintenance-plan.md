## 1. 소개

### 1.1 목적

본 문서는 로컬 CBCT 웹 뷰어 소프트웨어의 보안 유지보수 계획(Security Maintenance Plan)을 수립하기 위하여 작성되었다. 본 계획은 소프트웨어 전체 수명주기 동안 발생할 수 있는 보안 위협을 식별하고, 이에 대한 보안 통제를 정의하며, 보안 유지보수 활동을 체계적으로 관리하는 것을 목적으로 한다.

### 1.2 범위

본 계획은 다음 대상에 적용된다:

- 제품명: 로컬 CBCT 웹 뷰어 (Local CBCT Web Viewer)
- 소프트웨어 유형: 의료기기 소프트웨어 (SaMD)
- 분류 등급: II급 (일반의료기기)
- 운영 환경: 웹 브라우저 기반 로컬 실행 (Chrome, Edge)
- 플랫폼: Windows 10/11
- 네트워크: 인터넷 연결 불필요 (로컬 전용)

**적용 기간**: 소프트웨어 전체 수명주기 (개발 출시 후 폐기까지)

본 소프트웨어는 웹 브라우저 기반으로 로컬 환경에서 실행되며, 외부 네트워크 통신이 발생하지 않는다. 이러한 특성을 고려하여 물리적 보안, 로컬 데이터 보호, 의존 라이브러리 관리에 중점을 둔다.

### 5.3 보안 업데이트 절차

1. **취약점 접수**: 취약점 모니터링(MON-001 ~ MON-004) 또는 외부 제보를 통해 취약점 접수
2. **영향 평가**: 취약점이 본 소프트웨어에 미치는 영향 및 위험도 평가
3. **패치 우선순위 결정**: 위험도에 따라 PAT-001 ~ PAT-004 기준으로 우선순위 결정
4. **패치 개발**: 보안 수정 사항 개발 및 내부 테스트 수행
5. **검증**: 보안 패치에 대한 검증(Verification) 수행
6. **릴리즈**: 검증 완료 후 패치 버전 릴리즈
7. **배포**: 사용자에게 패치 배포 및 업데이트 안내
8. **기록**: 보안 업데이트 이력을 형상 관리 시스템에 기록

### 5.4 사고 대응 계획

| 단계 | 활동 | 상세 내용 | 담당 |
|------|------|----------|------|
| 1. 탐지 | 보안 사고 탐지 | 사용자 보고, 모니터링을 통한 보안 사고 탐지 | 개발팀 |
| 2. 분석 | 영향 범위 분석 | 사고의 영향 범위, 피해 규모, 원인 분석 | 개발팀, 품질관리팀 |
| 3. 격리 | 피해 확산 방지 | 추가 피해 방지를 위한 조치 (사용 중지 안내 등) | 개발팀 |
| 4. 복구 | 패치 개발 및 배포 | 사고 원인에 대한 보안 패치 개발 및 긴급 배포 | 개발팀 |
| 5. 검증 | 복구 확인 | 패치 적용 후 보안 사고 재발 방지 확인 | 품질관리팀 |
| 6. 보고 | 사고 보고서 작성 | 보안 사고 원인, 대응 내역, 재발 방지 대책을 포함한 보고서 작성 | 품질관리팀 |
