## 1. 개요

### 1.1 목적

본 문서는 "로컬 CBCT 웹 뷰어" 소프트웨어의 의도된 사용(Intended Use)을 정의한다. 이 소프트웨어는 치과 영역에서 촬영된 CBCT(Cone Beam Computed Tomography) 영상을 웹 브라우저 환경에서 조회, 분석할 수 있도록 지원하는 의료기기 소프트웨어(SaMD: Software as a Medical Device)이다.

### 1.2 적용 범위

본 문서는 PLAYG-1969 "로컬 CBCT 웹 뷰어" Intended Use 티켓에 대한 상세 문서이며, PA Gate(PLAYG-1961)의 승인 항목 중 하나로 관리된다.

## 3. 의도된 사용(Intended Use)

### 3.1 의도된 의료 목적

본 소프트웨어는 치과 영역에서 촬영된 CBCT 영상을 의료진이 웹 브라우저를 통해 조회하고 분석할 수 있도록 지원하는 **영상 조회 및 분석 보조 도구**이다.

구체적인 의료 목적은 다음과 같다:

1. **CBCT 영상 조회**: DICOM 형식의 CBCT 영상을 로컬 환경에서 로드하여 3단면(MPR: Axial, Coronal, Sagittal) 영상 및 3D 볼륨 렌더링으로 시각화
2. **영상 분석 보조**: 거리 측정, 각도 측정, ROI(관심영역) 표시 등의 분석 도구 제공
3. **진단 보조 정보 제공**: 환자 정보 및 영상 정보를 표시하여 의료진의 판독을 지원

> **주의**: 본 소프트웨어는 영상의 **조회 및 분석을 보조**하는 도구이며, 자동 진단(Auto-diagnosis) 기능은 포함하지 않는다. 최종 진단은 반드시 면허를 가진 의료진이 수행해야 한다.

### 3.2 의도된 사용자

| 사용자 유형 | 자격 요건 | 역할 |
|------------|----------|------|
| 치과의사 | 치과의사 면허 소지자 | CBCT 영상 판독 및 진단 |
| 구강악안면방사선과 전문의 | 해당 전문의 자격 소지자 | 전문적 영상 판독 |
| 치과 위생사 | 치과위생사 면허 소지자 (감독 하) | 영상 준비 및 기본 측정 |

### 3.3 의도된 사용 환경

| 환경 항목 | 요구 사양 |
|----------|----------|
| 실행 환경 | 웹 브라우저 (Chrome, Edge 최신 버전) |
| 운영체제 | Windows 10/11, macOS |
| 하드웨어 | WebGL 2.0 지원 GPU 탑재 컴퓨터 |
| 네트워크 | 인터넷 연결 불필요 (로컬 실행) |
| 사용 장소 | 치과 의원, 병원 진료실, 영상 판독실 |

### 3.4 의도된 환자 대상

- **대상**: 치과 영역 CBCT 촬영이 수행된 환자
- **연령 제한**: 특별한 연령 제한 없음 (단, 영상은 보호자 동의 하에 촬영된 것이어야 함)
- **대상 신체 부위**: 구강 및 악안면 영역 (치아, 악골, 부비동, 하악관 등)

## 4. 제품 기능 요약

본 소프트웨어의 핵심 기능은 다음과 같다. 상세 요구사항은 System Requirement Specification(PLAYG-1963)을 참조한다.

| 요구사항 ID | 기능명 | 요약 |
|------------|--------|------|
| SR-001 | DICOM 파일 로드 및 파싱 | DICOM 형식 CBCT 영상 파일 로드, 태그 파싱, 환자 정보 추출, 영상 데이터 디코딩 |
| SR-002 | MPR 3단면 실시간 렌더링 | Axial, Coronal, Sagittal 3단면 영상 실시간 생성 및 표시 |
| SR-003 | 3D 볼륨 렌더링 (Ray Casting) | WebGL 기반 Ray Casting 알고리즘을 통한 3D 볼륨 렌더링, 전송 함수 지원 |
| SR-004 | 3D 회전/확대/축소 제어 | 마우스/터치 입력을 통한 3D 뷰 회전, 확대, 축소 기능 |
| SR-005 | Window Level/Width 조절 | 영상 밝기(WL) 및 대비(WW) 사용자 제어 기능 |
| SR-006 | 거리 및 각도 측정 도구 | MPR 영상 위에 거리(mm) 및 각도(도) 측정 도구 제공 |
| SR-007 | ROI(관심영역) 표시 | 사각형/원형/자유곡선 형태의 ROI 표시 기능 |
| SR-008 | 환자 정보 표시 | DICOM 태그에서 추출한 환자 정보 화면 표시 |
| SR-009 | MPR-3D 뷰 동기화 | MPR 단면과 3D 뷰 간 위치/방향 양방향 동기화 |
| SR-010 | 렌더링 성능 요구사항 | 512³ 볼륨 기준 MPR ≥30fps, 3D ≥15fps, 초기 로딩 ≤5초 |
| SR-011 | 사용자 인터페이스 요구사항 | 웹 브라우저 기반 UI, Chrome/Edge 지원, 반응형 레이아웃 |
| SR-012 | 환자 데이터 보안 요구사항 | 로컬 환경에서만 데이터 처리, 외부 전송 금지, 접근 권한 제어 |
| SR-013 | 의료기기 소프트웨어 규제 요구사항 | MDRFW, IEC 62304 준수, V&V 문서화, 형상 관리 |
| SR-014 | 파노라믹 뷰 (Curved Planar Reformation) | 치아궁 곡선 정의 및 곡면 슬라이스의 평면 투영 표시 (진단 보조용) |

## 5. 의도되지 않은 사용 (Unintended Use)

다음의 사용 방법은 본 소프트웨어의 의도된 사용 범위를 벗어나며, 제조자는 이로 인한 어떠한 책임도 지지 않는다:

1. **치과 영역 외 CBCT 영상 분석**: 두경부, 흉부, 사지 등 치과 영역 외의 CBCT 영상 분석
2. **CT 영상 분석**: 일반 CT(Computed Tomography) 영상의 분석 (CBCT 전용)
3. **자동 진단**: 소프트웨어의 분석 결과를 직접적인 진단 근거로 단독 사용
4. **원격 진단**: 네트워크를 통한 원격 환자의 영상 전송 및 진단 (로컬 전용)
5. **수술 내비게이션**: 수술 중 실시간 내비게이션 목적으로의 사용
6. **영상 촬영 기기 제어**: CBCT 촬영 장치와의 직접 연동 또는 제어
7. **환자 모니터링**: 실시간 환자 상태 모니터링 목적으로의 사용
8. **비의료 목적 사용**: 교육 목적 이외의 비의료적 영상 분석

## 6. 안전 및 유효성 고려사항

### 6.1 안전성

| 항목 | 내용 |
|------|------|
| 데이터 보안 | 환자 데이터는 로컬 환경에서만 처리되며, 외부 네트워크로 전송하지 않음 (SR-012) |
| 데이터 무결성 | DICOM 파일 파싱 시 데이터 무결성 검증 수행 (SR-001) |
| 오류 처리 | 영상 로드 실패, 손상된 파일 등에 대한 명확한 오류 메시지 제공 |
| 접근 권한 | 로컬 파일 시스템 접근 권한 내에서만 동작 |

### 6.2 유효성

| 항목 | 내용 |
|------|------|
| 영상 정확성 | DICOM 표준 준수 파싱으로 영상 데이터의 정확성 보장 |
| 측정 정확성 | 거리 및 각도 측정 시 DICOM Pixel Spacing 정보를 활용한 정확한 측정값 제공 |
| 렌더링 품질 | 임상적으로 유의미한 영상 품질을 실시간으로 유지 (SR-010) |

### 6.3 임상적 유익성

1. **접근성 향상**: 웹 브라우저 기반으로 별도 소프트웨어 설치 없이 CBCT 영상 조회 가능
2. **편의성**: 로컬 환경에서 즉시 영상 분석 가능, 네트워크 의존성 없음
3. **분석 효율성**: MPR 3단면 및 3D 렌더링을 통한 다각도 영상 분석
4. **측정 정확도**: 디지털 측정 도구를 통한 정확한 거리 및 각도 측정
