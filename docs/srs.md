## 1. 소개

### 1.1 목적

본 문서는 "로컬 CBCT 웹 뷰어" 소프트웨어의 소프트웨어 요구사항 명세서(Software Requirements Specification, SRS)로서, 시스템 요구사항(SR-001 ~ SR-013)을 기반으로 소프트웨어가 충족해야 할 기능적, 비기능적 요구사항을 정의한다. Intended Use(PLAYG-1969)에 정의된 의도된 사용 범위 내에서 소프트웨어 요구사항을 명세한다.

### 1.2 범위

**적용 대상**:
- 치과 영역 CBCT 영상의 로컬 웹 브라우저 기반 조회 및 분석 소프트웨어
- DICOM 형식 CBCT 영상 파일의 파싱, 렌더링, 분석 기능
- MPR 3단면 영상 생성 및 3D 볼륨 렌더링
- 거리/각도 측정 및 ROI 표시 도구
- 환자 정보 표시
- MPR-3D 뷰 동기화

**적용 제외 대상**:
- 자동 진단(Auto-diagnosis) 기능
- 원격 영상 전송 및 원격 진단 기능
- CBCT 촬영 장치 제어 기능
- 치과 영역 외 CBCT 영상 분석

### 1.3 정의, 약어, 용어

|------|------|
| CBCT | Cone Beam Computed Tomography (콘빔 컴퓨터 단층 촬영) |

## 2. 전체 설명

### 2.1 제품 관점

본 소프트웨어는 웹 브라우저에서 동작하는 단독 실행형 클라이언트 애플리케이션이다. 서버 구성 요소가 없으며, 모든 데이터 처리는 사용자의 로컬 환경에서 수행된다.

- **실행 환경**: 웹 브라우저 (Chrome, Edge 최신 버전)
- **렌더링 엔진**: WebGL 2.0 기반
- **데이터 소스**: 사용자 로컬 파일 시스템의 DICOM 파일
- **네트워크**: 인터넷 연결 불필요 (완전 오프라인 동작)

### 2.2 제품 기능

본 소프트웨어의 주요 기능은 다음과 같다:

1. **DICOM 파일 처리**: CBCT 영상 파일의 로드, 파싱, 데이터 구조 변환
2. **MPR 렌더링**: Axial, Coronal, Sagittal 3단면 실시간 생성
3. **3D 렌더링**: Ray Casting 기반 3D 볼륨 시각화
4. **영상 조작**: Window Level/Width 조절, 3D 회전/확대/축소
5. **분석 도구**: 거리 측정, 각도 측정, ROI 표시
6. **환자 정보**: DICOM 태그 기반 환자 메타데이터 표시
7. **뷰 동기화**: MPR-3D 뷰 간 양방향 위치 동기화
8. **보안**: 로컬 전용 데이터 처리, 외부 전송 금지

### 2.3 사용자 특성

| 사용자 유형 | 자격 요건 | 역할 |
|------------|----------|------|
| 치과의사 | 치과의사 면허 소지자 | CBCT 영상 판독 및 진단 |
| 구강악안면방사선과 전문의 | 해당 전문의 자격 소지자 | 전문적 영상 판독 |
| 치과 위생사 | 치과위생사 면허 소지자 (감독 하) | 영상 준비 및 기본 측정 |

사용자는 기본적인 웹 브라우저 조작 능력을 갖추고 있어야 하며, 치과 영상 판독에 대한 전문 지식을 보유해야 한다.

### 2.4 제약사항

1. **브라우저 제약**: Chrome 및 Edge 최신 버전에서만 동작 보장
2. **하드웨어 제약**: WebGL 2.0 지원 GPU 필수
3. **성능 제약**: 512x512x512 볼륨 크기를 기준으로 성능 요구사항 정의
4. **네트워크 제약**: 네트워크 연결 없이 동작해야 함
5. **보안 제약**: 환자 데이터의 외부 전송 절대 금지
6. **규제 제약**: MDRFW, IEC 62304 규격 준수

### 2.5 가정 및 종속성

1. 사용자의 컴퓨터에 WebGL 2.0 지원 GPU가 탑재되어 있다고 가정한다.
2. 입력 데이터는 DICOM 표준을 준수하는 CBCT 영상 파일이라고 가정한다.
3. 소프트웨어는 의료기기 소프트웨어로서 MDRFW 및 IEC 62304에 따라 개발 및 관리된다.
4. 치과 영역 CBCT 영상에 한정하여 사용된다.

## 3. 기능적 요구사항

### 3.1 SR-001 DICOM 파일 로드 및 파싱

**ID**: SW-REQ-001
**System ID**: SR-001
**Jira 티켓**: PLAYG-1970
**Verification**: PLAYG-2267

DICOM 형식의 CBCT 영상 파일을 로컬 스토리지에서 로드하고 파싱하여 내부 데이터 구조로 변환하는 기능을 제공해야 한다.

**상세 요구사항**:

- SW-REQ-001-01: DICOM 파일 메타헤더(Dataset Meta-information)의 매직 바이트('DICM')를 확인하여 파일 형식을 검증해야 한다.
- SW-REQ-001-02: 필수 태그(Patient ID, Study Instance UID, Series Instance UID, SOP Instance UID, Rows, Columns, Bits Allocated, Pixel Data 등)의 존재 여부를 검증해야 한다.
- SW-REQ-001-03: 전송 구문(Transfer Syntax UID)이 지원되는지 확인해야 한다.
- SW-REQ-001-04: 파일이 손상되었거나 필수 태그가 누락된 경우 사용자에게 명확한 오류 메시지를 표시하고 로드를 중단해야 한다.
- SW-REQ-001-05: 파싱된 픽셀 데이터의 무결성을 검증해야 한다 (예: 예상 크기와 실제 크기 비교).
- SW-REQ-001-06: DICOM 태그 파싱, 환자 정보 추출, 영상 데이터 디코딩 기능을 포함해야 한다.

**검증 기준**:
- 유효한 DICOM 파일 로드 성공
- 손상된/비DICOM 파일에 대한 오류 메시지 표시
- 필수 태그 누락 시 로드 중단
- 픽셀 데이터 무결성 검증 통과

### 3.2 SR-002 MPR 3단면 실시간 렌더링

**ID**: SW-REQ-002
**System ID**: SR-002
**Jira 티켓**: PLAYG-1971
**Verification**: PLAYG-2268

CBCT 볼륨 데이터로부터 Axial, Coronal, Sagittal 3단면 영상을 실시간으로 생성 및 표시해야 한다. 사용자 조작에 따른 단면 위치 이동 및 갱신을 지원해야 한다.

**상세 요구사항**:

- SW-REQ-002-01: 각 단면의 픽셀 값이 원시 볼륨 데이터에 정확히 매핑되어야 한다.
- SW-REQ-002-02: 단면 위치(position) 및 방향(orientation)이 DICOM Image Orientation/Position 태그에 일치해야 한다.
- SW-REQ-002-03: 보간(interpolation) 알고리즘이 해부학적 구조를 왜곡하지 않아야 한다.
- SW-REQ-002-04: 단면 이동 시 실시간으로 정확한 영상이 갱신되어야 한다.
- SW-REQ-002-05: 기준 영상 셋과의 비교를 통해 렌더링 정확성을 검증할 수 있어야 한다.

**검증 기준**:
- 3단면(Axial, Coronal, Sagittal) 정확한 렌더링
- DICOM Image Orientation/Position 태그 일치
- 실시간 갱신 응답성
- 보간 왜곡 없음

---

### 3.3 SR-003 3D 볼륨 렌더링 (Ray Casting)

**ID**: SW-REQ-003
**System ID**: SR-003
**Jira 티켓**: PLAYG-1972
**Verification**: PLAYG-2269

WebGL 기반 Ray Casting 알고리즘을 통한 3D 볼륨 렌더링을 제공해야 한다. 전송 함수(Transfer Function)를 통한 투명도 및 색상 매핑을 지원해야 한다.

**상세 요구사항**:

- SW-REQ-003-01: 기본 전송 함수는 주요 해부학적 구조(치아, 골조직, 연조직, 공기)가 적절히 구분되도록 설정되어야 한다.
- SW-REQ-003-02: 전송 함수의 불투명도(opacity) 및 색상(color) 매핑이 사용자 의도대로 적용되어야 한다.
- SW-REQ-003-03: 전송 함수 변경 시 3D 렌더링이 즉시 갱신되어야 한다.
- SW-REQ-003-04: 잘못된 전송 함수 값으로 인해 해부학적 구조가 가려지지 않아야 한다.
- SW-REQ-003-05: 3D 뷰는 보조 수단이며, MPR이 주 판독 수단임을 사용자 가이드에 명시해야 한다.

**검증 기준**:
- 해부학적 구조(치아, 골조직, 연조직, 공기) 구분 표시
- 전송 함수 변경 시 즉시 갱신
- 불투명도/색상 매핑 정확성
- 사용자 가이드 내 MPR 주 판독 수단 명시

### 3.4 SR-004 3D 회전/확대/축소 제어

**ID**: SW-REQ-004
**System ID**: SR-004
**Jira 티켓**: PLAYG-1973
**Verification**: PLAYG-2270

3D 렌더링 뷰에서 마우스/터치 입력을 통한 회전, 확대, 축소 기능을 제공해야 한다. 직관적인 카메라 조작 인터페이스를 제공해야 한다.

**상세 요구사항**:

- SW-REQ-004-01: 마우스 드래그에 따른 카메라 회전이 자연스럽고 예측 가능해야 한다.
- SW-REQ-004-02: 확대/축소 시 카메라 위치가 올바르게 계산되어야 한다.
- SW-REQ-004-03: 카메라 행렬(camera matrix) 계산에 수치 오차가 누적되지 않아야 한다.
- SW-REQ-004-04: 터치 입력(핀치, 팬)도 마우스 입력과 동일하게 동작해야 한다.
- SW-REQ-004-05: 뷰 리셋 시 카메라가 초기 위치로 정확히 복원되어야 한다.

**검증 기준**:
- 마우스/터치 입력에 대한 자연스러운 회전 응답
- 확대/축소 시 카메라 위치 정확성
- 뷰 리셋 후 초기 위치 복원 정확성
- 수치 오차 누적 없음 확인

### 3.5 SR-005 Window Level/Width 조절

**ID**: SW-REQ-005
**System ID**: SR-005
**Jira 티켓**: PLAYG-1974
**Verification**: PLAYG-2271

영상의 Window Level(WL) 및 Window Width(WW) 값을 조절하여 영상의 밝기와 대비를 사용자가 제어할 수 있는 기능을 제공해야 한다.

**상세 요구사항**:

- SW-REQ-005-01: WL/WW 값에 따른 픽셀-휘도 매핑이 선형적으로 정확해야 한다.
- SW-REQ-005-02: 기본 WL/WW 값은 CBCT 영상에 적합한 값으로 설정되어야 한다.
- SW-REQ-005-03: WL/WW 조절 시 진단에 필요한 조직 대비가 손실되지 않아야 한다.
- SW-REQ-005-04: 한계값(clipping) 처리가 올바르게 수행되어야 한다.
- SW-REQ-005-05: WL/WW 리셋 기능을 제공하여 기본값으로 복원할 수 있어야 한다.
- SW-REQ-005-06: 사용자가 조절한 WL/WW 값이 다른 뷰(MPR/3D)에 일관되게 적용되어야 한다.

**검증 기준**:
- 픽셀-휘도 선형 매핑 정확성
- CBCT 기본값 적절성
- 뷰 간 WL/WW 일관성
- 리셋 기능 동작 확인

### 3.6 SR-006 거리 및 각도 측정 도구

**ID**: SW-REQ-006
**System ID**: SR-006
**Jira 티켓**: PLAYG-1975
**Verification**: PLAYG-2272

MPR 단면 영상 위에 거리(mm) 및 각도(도) 측정 도구를 제공해야 한다. 측정선/측정각도 표시 및 측정값 실시간 표시를 지원해야 한다.

**상세 요구사항**:

- SW-REQ-006-01: 거리 측정 시 DICOM Pixel Spacing 정보를 사용하여 mm 단위로 정확히 변환해야 한다.
- SW-REQ-006-02: Pixel Spacing 정보가 누락된 경우 사용자에게 경고를 표시하고, 픽셀 단위로 표시해야 한다.
- SW-REQ-006-03: 각도 측정 시 세 점을 통한 각도 계산이 수학적으로 정확해야 한다.
- SW-REQ-006-04: 측정선이 MPR 단면 위에 정확히 표시되어야 한다.
- SW-REQ-006-05: 측정 결과값이 소수점 둘째 자리까지 표시되어야 한다.
- SW-REQ-006-06: 단위 변환(mm, degree)이 정확해야 한다.

**검증 기준**:
- Pixel Spacing 기반 mm 단위 변환 정확성
- Pixel Spacing 누락 시 경고 표시
- 각도 계산 수학적 정확성
- 소수점 둘째 자리까지 결과 표시

### 3.7 SR-007 ROI(관심영역) 표시

**ID**: SW-REQ-007
**System ID**: SR-007
**Jira 티켓**: PLAYG-1976
**Verification**: PLAYG-2273

MPR 단면 영상에서 사용자가 지정한 관심영역(ROI)을 사각형/원형/자유곡선 형태로 표시하는 기능을 제공해야 한다.

**상세 요구사항**:

- SW-REQ-007-01: 사각형, 원형, 자유곡선 ROI가 화면 좌표와 볼륨 좌표 간 정확히 매핑되어야 한다.
- SW-REQ-007-02: 화면 해상도 변경 시 ROI 위치와 크기가 올바르게 유지되어야 한다.
- SW-REQ-007-03: MPR 단면 이동 시 ROI가 해당 단면에 정확히 표시되어야 한다.
- SW-REQ-007-04: ROI 생성, 수정, 삭제 기능이 정상 동작해야 한다.

**검증 기준**:
- 화면-볼륨 좌표 간 정확한 매핑
- 해상도 변경 시 ROI 유지
- 단면 이동 시 ROI 정확 표시
- ROI 생성/수정/삭제 동작

### 3.8 SR-008 환자 정보 표시

**ID**: SW-REQ-008
**System ID**: SR-008
**Jira 티켓**: PLAYG-1977
**Verification**: PLAYG-2274

DICOM 파일에서 추출한 환자 정보를 화면에 정확히 표시해야 한다.

**상세 요구사항**:

- SW-REQ-008-01: Patient Name, Patient ID, Patient Birth Date, Study Date, Modality 등 필수 환자 정보가 DICOM 태그에서 정확히 파싱되어야 한다.
