## 1. 소개

### 1.1 목적

본 문서는 "로컬 CBCT 웹 뷰어" 소프트웨어의 위험 관리 계획(Risk Management Plan)을 수립한다. ISO 14971:2019(의료기기 - 위험 관리의 적용) 및 IEC 62304:2006+A1:2015(의료기기 소프트웨어 - 소프트웨어 생명주기 프로세스)의 요구사항에 따라 소프트웨어 개발 전반에 걸친 위험 관리 활동을 정의한다.

### 1.2 범위

본 문서는 PLAYG-1966 "[Risk Management Plan]" 티켓에 대한 상세 문서이며, PA Gate(PLAYG-1961)의 승인 항목 중 하나로 관리된다.

## 2. 위험 관리 정책

### 2.1 위험 허용 기준

본 소프트웨어는 Classification(PLAYG-1964)에 따라 IEC 62304 Software Safety Class A로 분류되었다. Class A는 "어떠한 상해나 건강 악화를 초래할 가능성이 없거나 극히 낮은 소프트웨어"에 해당한다.

위험 허용 기준은 다음과 같다.

| 위험 수준 | 허용 여부 | 조치 |
|-----------|----------|------|
| 상 (High) | 허용 불가 | 반드시 통제 조치로 저감 필요 |
| 중 (Medium) | ALARP 원칙에 따라 수용 | 가능한 한 낮게 유지(As Low As Reasonably Practicable) |
| 저 (Low) | 수용 | 모니터링 및 검토 |

### 2.2 위험 평가 방법론

ISO 14971:2019에 따라 다음과 같은 위험 평가 방법론을 적용한다.

**가능성 등급**:

| 등급 | 점수 | 기준 |
|------|------|------|
| 높음 | 3 | 정상 사용 조건에서 빈번하게 발생 가능 |
| 보통 | 2 | 비정상 조건에서 발생 가능 |
| 낮음 | 1 | 극히 드문 상황에서만 발생 가능 |

**심각도 등급**:

| 등급 | 점수 | 기준 |
|------|------|------|
| 심각 | 3 | 환자 또는 사용자에게 심각한 상해 또는 건강 악화 초래 가능 |
| 보통 | 2 | 환자 또는 사용자에게 일시적이거나 경미한 상해 초래 가능 |
| 경미 | 1 | 상해나 건강 악화 가능성 없음 |

**위험 평가 매트릭스**:

|  | 심각도 1 (경미) | 심각도 2 (보통) | 심각도 3 (심각) |
|--|----------------|----------------|----------------|
| **가능성 3 (높음)** | 저 | 상 | 상 |
| **가능성 2 (보통)** | 저 | 중 | 상 |
| **가능성 1 (낮음)** | 저 | 저 | 중 |

## 3. 위험 분석

### 3.1 위험 식별 방법

위험 식별은 다음 방법을 통해 수행한다:

- **Intended Use 분석**: IU 문서(PLAYG-1962)의 의도된 사용목적, 사용 환경, 경고사항 분석
- **시스템 요구사항 분석**: SyRS(PLAYG-1963)의 각 시스템 요구사항(SR-001 ~ SR-013)에 대한 고장 모드 및 영향 분석
- **사용 시나리오 분석**: 정상 사용 및 오사용 시나리오 도출
- **외부 요인 분석**: 하드웨어, 브라우저, 환경 요인 분석

### 3.2 위해 상황 식별

IU 문서(PLAYG-1962)의 Indication, Use Environment, Warnings 필드와 SyRS(PLAYG-1963)의 요구사항을 기반으로 위해 상황을 도출한다.

**제품 컨텍스트**:

- 제품명: 로컬 CBCT 웹 뷰어 (Local CBCT Web Viewer)
- 의료 목적: 치과 영역 CBCT 영상의 조회 및 분석 보조 (자동 진단 기능 없음)
- 사용 환경: 치과 의원, 병원 진료실, 영상 판독실
- 사용자: 치과의사, 구강악안면방사선과 전문의, 치과 위생사
- 분류: II급 (일반의료기기), Software Safety Class A

## 4. 위험 평가

### 4.1 위험 평가 매트릭스 적용 결과

ISO 14971:2019의 위험 평가 매트릭스를 적용하여 모든 위해 상황을 평가하였다. Software Safety Class A에 해당하는 본 소프트웨어는 치명적인 위험이 발생할 가능성이 낮으나, 영상 표시 및 측정 관련 위해 상황(H-01, H-02, H-04, H-05)은 상위험으로 평가되어 즉각적인 통제가 필요하다.

### 4.2 평가 결과

**상위험 (4건)**: 즉각적 통제 조치 필요

- H-01: 영상 왜곡 또는 부정확한 영상 표시
- H-02: MPR 단면 영상 렌더링 왜곡
- H-04: 측정값(거리, 각도) 부정확
- H-05: 환자 정보 오표시

**중위험 (5건)**: ALARP 원칙에 따른 통제

- H-03: 3D 볼륨 렌더링 부정확
- H-07: 비지원 브라우저에서 오동작
- H-08: 환자 데이터 유출
- H-09: 비의료진에 의한 영상 오해석
- H-12: 부적절한 WL/WW 설정

**저위험 (4건)**: 모니터링

- H-06: 성능 저하
- H-10: 비치과 영역 영상 오해석
- H-11: MPR-3D 뷰 동기화 오류
- H-13: 소프트웨어 오류 발생 시 사용자 혼란

## 7. 위험 관리 보고

### 7.1 보고서 작성 기준

위험 관리 보고서는 다음 시점에 작성한다:

1. **PA Phase 완료 시**: 위험 관리 계획 및 초기 위험 평가 결과 보고
2. **개발 Phase 완료 시**: 통제 조치 구현 결과 및 검증 결과 보고
3. **출하 전**: 전체 위험 관리 활동 결과 및 잔류 위험 수용 평가 보고

### 7.2 검토 주기

| 검토 항목 | 주기 |
|----------|------|
| 위해 상황 재평가 | 각 개발 Phase 전환 시 |
| 통제 조치 효과성 검토 | 검증(V&V) 완료 후 |
| 잔류 위험 수용성 재평가 | 변경 요청 발생 시, 출하 전 |
