## 3. 의료기기 분류

### 3.1 분류 등급

| 항목 | 내용 |
|------|------|
| 분류 등급 | **II급 (일반의료기기)** |
| 분류 근거 | 의료기기법 시행규칙 별표 5 (의료기기 분류기준) |
| 분류 코드 | 해당 분류번호 적용 |
| 규제 체계 | MDRFW (Medical Device Regulation Framework) |

### 3.2 분류 사유

1. **용도**: 치과 영역 CBCT 영상의 조회 및 분석 보조
2. **작동 원리**: DICOM 형식 CBCT 영상 파일을 로드하여 MPR 3단면 및 3D 볼륨 렌더링으로 시각화
3. **침습성**: 비침습적 (Non-invasive) - 환자 접촉 없음
4. **에너지 공급**: 전기적 에너지 사용 (컴퓨터 하드웨어 구동)
5. **위험도**: 간접적 진단 보조 도구로서 중등도 위험
6. **독립성**: 자동 진단 기능 없음, 최종 진단은 의료진이 수행

### 3.3 분류 판단 근거

- 본 소프트웨어는 치과 영역 CBCT 영상을 시각화하여 의료진의 판독을 보조하는 영상 조회 소프트웨어임
- 자동 진단(Auto-diagnosis) 기능이 포함되지 않아 진단 결과에 직접적 영향을 미치지 않음
- 환자 데이터는 로컬 환경에서만 처리되어 네트워크를 통한 데이터 유출 위험이 제한적임
- 영상 조회 및 측정 도구 제공으로 임상적 유익성이 확인됨
- 위 요소를 종합적으로 고려하여 **II급 (일반의료기기)** 로 분류함

## 4. Software Safety Classification (IEC 62304)

### 4.1 Software Safety Class

| 항목 | 내용 |
|------|------|
| Software Safety Class | **Class A** |
| 규격 | IEC 62304:2006+A1:2015 |
| 분류 근거 | 소프트웨어가 치명적인 상해나 심각한 건강 악화를 초래할 가능성이 낮음 |

### 4.2 Software Safety Class 분류 사유

IEC 62304 Section 4.3에 따라 Software Safety Class를 다음과 같이 판단한다:

| 조건 | 판단 | 근거 |
|------|------|------|
| 치명적 상해 초래 가능성 | **없음** | 자동 진단 기능이 없으며, 영상 조회/분석 보조 도구에 불과함 |
| 심각한 건강 악화 초래 가능성 | **매우 낮음** | 최종 진단은 면허를 가진 의료진이 수행하며, 소프트웨어는 보조 도구임 |
| 비심각한 상해 초래 가능성 | **낮음** | 영상 표시 오류 시 의료진이 다른 수단으로 확인 가능함 |
| 소프트웨어 고장 시 영향 | **제한적** | 소프트웨어 고장 시 영상 조회 불가 상태가 되며, 기존 판독 방식으로 대체 가능 |

**결론**: IEC 62304에 따라 본 소프트웨어는 **Class A** 로 분류한다.
(참고: Class A = "어떠한 상해나 건강 악화를 초래할 가능성이 없거나 극히 낮은 소프트웨어")
